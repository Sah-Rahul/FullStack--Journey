# Day 3 – MongoDB + Mongoose + Create & Get Users

## ✅ Topics Covered
- MongoDB local connection using Mongoose
- .env config with dotenv
- Express routes with GET and POST
- User model schema validation

## ▶️ Run
```bash
npm install
npm run dev
```
## 📂 API Endpoints
- GET /api/users → All users

- POST /api/users → Create user with name & email
