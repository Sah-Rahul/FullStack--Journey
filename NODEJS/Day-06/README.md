# 📦 Day 6 - MongoDB + Mongoose Integration

## 🔥 What I Learned
- Setup MongoDB locally
- Connect to MongoDB using `mongoose`
- Created `.env` for environment variables
- Defined the first data model: `Product`

## 📁 Folder Structure
```bash
config/ # MongoDB connection
models/ # All Mongoose schemas/models
index.js # Main server
```

## ⚙️ How to Run
1. Start MongoDB server locally (or use MongoDB Atlas)
2. Add `.env` file with `MONGO_URI`
3. Run server:
```bash
npm install
npm run dev
```
